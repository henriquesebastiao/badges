## ⚡ Quick Start

Pick any badge below, copy the Markdown snippet, and paste it into your `README.md`:

```markdown
![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)
```

Result: ![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

> **Tip:** Press <kbd>Ctrl</kbd>+<kbd>F</kbd> to search for any badge on this page.

## 🔧 Customization

Badges follow a simple URL pattern. Change any part to match your brand:

```
https://img.shields.io/badge/<LABEL>-<COLOR>?style=<STYLE>&logo=<LOGO>&logoColor=<LOGO_COLOR>
```

**Example — inverting a badge's colors:**

| Variant | Badge | Background | Logo color |
|---------|-------|-----------|------------|
| Dark | ![Markdown Dark](https://img.shields.io/badge/Markdown-000000?style=flat&logo=markdown&logoColor=white) | `000000` | `white` |
| Light | ![Markdown Light](https://img.shields.io/badge/Markdown-ffffff?style=flat&logo=markdown&logoColor=black) | `ffffff` | `black` |

> Find any logo name and its official brand color at **[simpleicons.org](https://simpleicons.org/)**.
